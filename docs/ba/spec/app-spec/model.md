# Модель

## Термины

### critical_action
- отменить
- повторить
- выполнить
- отчитаться

### field
- ссылка (ссылка Pinterest: на одну картинку или на альбом)
- папка_сохранения (каталог, куда складываются скачанные файлы; меняется пользователем и запоминается)
- прогресс (доля выполненного по текущей загрузке)
- скорость (текущая скорость загрузки)
- список_файлов (имена скачанных файлов текущей загрузки)
- токен_pinterest (токен или cookie Pinterest, вводится в GUI и хранится в системном хранилище)
- путь_к_gallery_dl (путь к бинарнику gallery-dl, если он не найден в PATH)
- лог (вывод gallery-dl, показывается для диагностики)

### role
- владелец (единственный пользователь приложения; он же владелец продукта)
- загрузка (автоматический исполнитель: внешний бинарник gallery-dl)

### state
- в_очереди (ссылка принята, загрузка ждёт своей очереди)
- выполняется (идёт скачивание: видны прогресс, скорость и счётчик)
- завершена (скачивание закончилось, показан итог: скачано, пропущено, ошибок)
- ошибка (загрузка не удалась: приложение показывает сообщение и предлагает повторить)
- отменена (пользователь остановил загрузку)

## Что решено

### field_after_send
- `field_after_send[лог]` = frozen — FACT-046 (derived), rationale: лог — поток вывода исполнителя, его не редактируют
- `field_after_send[папка_сохранения]` = editable — FACT-040 (derived), rationale: папку сохранения меняют в любой момент: это каталог назначения, а не часть содержимого загрузки
- `field_after_send[прогресс]` = frozen — FACT-063 (derived), rationale: прогресс — отчёт о том, что уже произошло; его не редактируют, его выдаёт исполнитель
- `field_after_send[путь_к_gallery_dl]` = editable — FACT-045 (derived), rationale: путь к бинарнику — настройка окружения, её правят когда угодно
- `field_after_send[скорость]` = frozen — FACT-064 (derived), rationale: скорость — измерение, его не редактируют вручную
- `field_after_send[список_файлов]` = frozen — FACT-065 (derived), rationale: список файлов — отчёт о факте скачанного, а не ввод пользователя
- `field_after_send[ссылка]` = frozen — FACT-062 (derived), rationale: ссылка определяет, что именно качать; после старта её смена означала бы другую загрузку
- `field_after_send[токен_pinterest]` = editable — FACT-044 (derived), rationale: токен можно заменить в любой момент: он не часть постановки загрузки, а условие доступа к сайту

### field_owner
- `field_owner[лог]` = загрузка — FACT-038 (derived), rationale: лог — это вывод внешнего бинарника, он попадает в поле от исполнителя
- `field_owner[папка_сохранения]` = владелец — FACT-032 (user), T2: "Оставляй умолчание, но у меня ru-локаль, так что у меня это будет `/home/sato/Изображения/Pinterest/`"
- `field_owner[прогресс]` = загрузка — FACT-059 (derived), rationale: прогресс идёт от исполнителя: он считает скачанное и сообщает состояние
- `field_owner[путь_к_gallery_dl]` = владелец — FACT-037 (derived), rationale: путь к бинарнику указывает владелец, если gallery-dl не найден в PATH: выбор пути — его решение
- `field_owner[скорость]` = загрузка — FACT-060 (derived), rationale: скорость измеряет исполнитель по факту передачи файлов
- `field_owner[список_файлов]` = загрузка — FACT-061 (derived), rationale: имена файлов знает только тот, кто их качает
- `field_owner[ссылка]` = владелец — FACT-031 (user), T2: "Да, одно поле."
- `field_owner[токен_pinterest]` = владелец — FACT-036 (user), T2: "Желательно что бы было безопаснее, что бы нельзя было просто достать куки или еще что-то."

### reversible
- `reversible[выполнить]` = no — FACT-081 (derived), rationale: запуск загрузки необратим: начав качать, отменить это нельзя — можно только остановить саму загрузку
- `reversible[отменить]` = yes — FACT-047 (derived), rationale: отменённую загрузку можно повторить (TR-008), то есть отмена обратима
- `reversible[отчитаться]` = no — FACT-082 (derived), rationale: отчёт — финальная запись по загрузке, отменить его нельзя
- `reversible[повторить]` = no — FACT-048 (derived), rationale: повтор запускает новую попытку; отменить саму попытку нельзя, отмена относится к загрузке, а не к её повтору

### rights
- `rights[владелец,выполнить,в_очереди]` = deny — FACT-067 (derived), rationale: владелец не выполняет загрузку сам: выполнение инициирует исполнитель (TR-009)
- `rights[владелец,выполнить,выполняется]` = deny — FACT-068 (derived), rationale: идущую загрузку выполняет исполнитель, а не владелец
- `rights[владелец,выполнить,завершена]` = deny — FACT-069 (derived), rationale: выполнение завершилось вместе с загрузкой; повторно выполнять завершённое нельзя
- `rights[владелец,выполнить,отменена]` = deny — FACT-070 (derived), rationale: отменённая загрузка ждёт явного повтора, сама выполнение не начинается
- `rights[владелец,выполнить,ошибка]` = deny — FACT-071 (derived), rationale: ошибочная загрузка ждёт явного повтора, сама выполнение не начинается
- `rights[владелец,отменить,в_очереди]` = allow — FACT-001 (user), T2: "Допускается несколько загрузок одновременно"
- `rights[владелец,отменить,выполняется]` = allow — FACT-002 (derived), rationale: владелец останавливает идущую загрузку: из выполняется есть дуга TR-005 по событию остановка_пользователем с инициатором владелец
- `rights[владелец,отменить,завершена]` = deny — FACT-003 (derived), rationale: из завершена в графе нет исходящих дуг: загрузка уже отчиталась, отменять нечего
- `rights[владелец,отменить,отменена]` = deny — FACT-005 (derived), rationale: из отменена исходящая дуга только повтор (TR-008); отменять уже отменённую загрузку бессмысленно
- `rights[владелец,отменить,ошибка]` = deny — FACT-004 (derived), rationale: из ошибки исходящая дуга только повтор (TR-007); отменять нечего — загрузка уже остановилась сама
- `rights[владелец,отчитаться,в_очереди]` = deny — FACT-072 (derived), rationale: отчёт есть только о завершившейся загрузке; в очереди отчитываться не о чем
- `rights[владелец,отчитаться,выполняется]` = deny — FACT-073 (derived), rationale: отчёт подводит исполнитель (TR-010, TR-011), у владельца такой дуги нет: он получает готовый итог, а не подводит его сам
- `rights[владелец,отчитаться,завершена]` = deny — FACT-083 (derived), rationale: дуги с действием отчитаться из завершена в графе нет: подведение итога происходит из выполняется (TR-010), а в завершена владелец уже смотрит готовый результат
- `rights[владелец,отчитаться,отменена]` = deny — FACT-084 (derived), rationale: дуги с действием отчитаться из отменена в графе нет: отмена — это остановка (TR-005, TR-006), итог по ней владелец видит из выполняется
- `rights[владелец,отчитаться,ошибка]` = deny — FACT-085 (derived), rationale: дуги с действием отчитаться из ошибка в графе нет: сбой подводится из выполняется (TR-011)
- `rights[владелец,повторить,в_очереди]` = deny — FACT-006 (derived), rationale: повтор есть только из ошибки (TR-007) и отменена (TR-008); из в_очереди повтор не выводится
- `rights[владелец,повторить,выполняется]` = deny — FACT-007 (derived), rationale: повтор есть только из ошибки (TR-007) и отменена (TR-008); идущую загрузку не повторяют, её ждут
- `rights[владелец,повторить,завершена]` = deny — FACT-008 (derived), rationale: завершена — терминальное состояние, повтор из него не выводится
- `rights[владелец,повторить,отменена]` = allow — FACT-010 (derived), rationale: из отменена есть дуга повтор (TR-008) с инициатором владелец: отменённую загрузку можно запустить заново
- `rights[владелец,повторить,ошибка]` = allow — FACT-009 (user), T2: "Оставляй."
- `rights[загрузка,выполнить,в_очереди]` = allow — FACT-074 (derived), rationale: из в_очереди загрузку запускает исполнитель (TR-009)
- `rights[загрузка,выполнить,выполняется]` = n/a — FACT-075 (derived), rationale: выполнение уже идёт: повторно запускать из выполняется нельзя
- `rights[загрузка,выполнить,завершена]` = n/a — FACT-076 (derived), rationale: завершена — терминальное состояние, выполнение в нём неприменимо
- `rights[загрузка,выполнить,отменена]` = n/a — FACT-077 (derived), rationale: из отменена выходит только повтор по решению владельца (TR-008)
- `rights[загрузка,выполнить,ошибка]` = n/a — FACT-078 (derived), rationale: из ошибки выходит только повтор по решению владельца (TR-007)
- `rights[загрузка,отменить,в_очереди]` = n/a — FACT-011 (derived), rationale: gallery-dl не отменяет загрузку, пока она в очереди: решение об отмене принимает владелец
- `rights[загрузка,отменить,выполняется]` = n/a — FACT-012 (derived), rationale: отмену инициирует владелец (TR-005); исполнитель не инициирует отмену, а подчиняется ей
- `rights[загрузка,отменить,завершена]` = n/a — FACT-013 (derived), rationale: завершена — терминальное состояние, отмена в нём неприменима
- `rights[загрузка,отменить,отменена]` = n/a — FACT-015 (derived), rationale: из отменена выходит только повтор (TR-008) по решению владельца
- `rights[загрузка,отменить,ошибка]` = n/a — FACT-014 (derived), rationale: из ошибки выходит только повтор (TR-007) по решению владельца
- `rights[загрузка,отчитаться,в_очереди]` = deny — FACT-079 (derived), rationale: в очереди отчитываться не о чем: загрузка ещё не началась
- `rights[загрузка,отчитаться,выполняется]` = allow — FACT-080 (derived), rationale: исполнитель, доведший загрузку до конца, отчитывается о результате (TR-010, TR-011)
- `rights[загрузка,отчитаться,завершена]` = deny — FACT-086 (derived), rationale: дуги с действием отчитаться из завершена в графе нет: итог подводится переходом в завершена (TR-010), а не из неё
- `rights[загрузка,отчитаться,отменена]` = deny — FACT-087 (derived), rationale: дуги с действием отчитаться из отменена в графе нет: остановка — это TR-005 и TR-006, а отчётность из выполняется
- `rights[загрузка,отчитаться,ошибка]` = deny — FACT-088 (derived), rationale: дуги с действием отчитаться из ошибка в графе нет: сбой — это переход в ошибка (TR-011), а отчётность из выполняется
- `rights[загрузка,повторить,в_очереди]` = n/a — FACT-016 (derived), rationale: повтор инициирует владелец (TR-007, TR-008), исполнитель сам не перезапускает загрузку
- `rights[загрузка,повторить,выполняется]` = n/a — FACT-017 (derived), rationale: повтор инициирует владелец (TR-007, TR-008), исполнитель сам не перезапускает загрузку
- `rights[загрузка,повторить,завершена]` = n/a — FACT-018 (derived), rationale: завершена — терминальное состояние, повтор в нём неприменим
- `rights[загрузка,повторить,отменена]` = n/a — FACT-020 (derived), rationale: повтор инициирует владелец (TR-008), исполнитель не перезапускает загрузку сам
- `rights[загрузка,повторить,ошибка]` = n/a — FACT-019 (derived), rationale: повтор инициирует владелец (TR-007), исполнитель не перезапускает загрузку сам

### state_timeout
- `state_timeout[в_очереди]` = нет: загрузка ждёт в очереди, пока владелец не остановит её или не освободится место — FACT-049 (derived), rationale: очередь не имеет срока: число параллельных загрузок ограничено только возможностями машины, а ожидание не истекает
- `state_timeout[выполняется]` = нет: загрузка идёт, пока файлы не скачаны, не сорвётся и не будет остановлена владельцем — FACT-066 (derived), rationale: из выполняется выходят три дуги (TR-003, TR-004, TR-005), ни одна из них не привязана к сроку
- `state_timeout[завершена]` = нет: итог показывается, пока пользователь не уберёт загрузку из списка — FACT-051 (derived), rationale: завершена — терминальное состояние, из него выходов в графе нет, значит срок не применим
- `state_timeout[отменена]` = нет: отменённая загрузка ждёт решения владельца — повторить или убрать — FACT-053 (derived), rationale: из отменена выходит только повтор (TR-008); срока, по которому отмена рассыпается сама, нет
- `state_timeout[ошибка]` = нет: ошибка ждёт решения владельца — повторить или убрать — FACT-052 (derived), rationale: из ошибки выходит только повтор (TR-007); срока, по которому ошибка рассыпается сама, нет

### visibility
- `visibility[владелец,в_очереди]` = limited — FACT-054 (derived), rationale: в очереди загрузка ещё не идёт: видны ссылка и папка сохранения, но ни прогресса, ни скорости, ни файлов ещё нет
- `visibility[владелец,выполняется]` = full — FACT-022 (user), T2: "Оставляй умолчание, но добавь еще скорость загрузки и сколько сколько скачано «скачано X из Y»."
- `visibility[владелец,завершена]` = full — FACT-023 (user), T2: "Да, оставляй так с итогом."
- `visibility[владелец,отменена]` = full — FACT-025 (derived), rationale: после отмены владельцу доступен итог по загрузке и лог: иначе он не поймёт, что именно прервалось
- `visibility[владелец,ошибка]` = full — FACT-024 (user), T2: "Оставляй."
- `visibility[загрузка,в_очереди]` = limited — FACT-055 (derived), rationale: исполнитель в очереди не работает; ему доступны только параметры запуска, которые получит при старте
- `visibility[загрузка,выполняется]` = full — FACT-056 (derived), rationale: исполнитель в ходе загрузки видит всё, что касается его работы: файлы, счётчики, лог
- `visibility[загрузка,завершена]` = full — FACT-057 (derived), rationale: исполнитель доводит загрузку до конца и отдаёт результат: он видит всё своё состояние
- `visibility[загрузка,отменена]` = full — FACT-030 (derived), rationale: исполнитель останавливается по команде владельца и знает, что произошло
- `visibility[загрузка,ошибка]` = full — FACT-058 (derived), rationale: исполнитель знает, чем загрузка кончилась: без этого он не может отдать владельцу диагностику
